# RNDM Chat — сайт по дизайну Figma

Автономный сайт-прототип компьютерного интерфейса RNDM Chat 2.0. Основан на последнем доступном описании макета Figma и оригинальных цветах, шрифте и графике из предоставленного архива RNDM 2.0.

## Запуск

1. Распакуйте ZIP.
2. Откройте `index.html` в браузере. Для наиболее стабильной работы можно запустить в папке простейший локальный сервер: `python -m http.server 8000` и открыть `http://localhost:8000`.
3. Все файлы локальные; интернет не требуется.

## Что работает в демонстрации

- Навигация по 16 разделам, чаты, групповые переписки, каналы, новости, клипы, звонки, контакты, рулетка, игры, маркет, банк, облако, профиль, настройки, админка.
- Создание локальных чатов, групп, каналов и постов, отправка локальных текстовых сообщений, поиск по списку, реакции, фильтры, редактирование профиля.
- Тапалка, подарки и баланс с демонстрационными транзакциями, настройки темы и отображения.
- Сохранение состояния в localStorage.

## Ограничения

Это **фронтенд-прототип**, а не исходная рабочая соцсеть: нет входа в аккаунты, Supabase, передачи сообщений другим пользователям, настоящих видео/звонков, передачи файлов или реальной банковской системы. Сообщения, пользователи, публикации, админ-действия и денежные суммы здесь демонстрационные. Скриншоты актуального Figma удалось получить не полностью из-за ограничения инструментов на тарифе Starter, поэтому точное пиксельное совпадение со всеми фреймами Figma не подтверждено.

Исходники: `index.html`, `styles.css`, `app.js` и изображения в корне.
